Terraform, CloudFormation, and infrastructure automation.

Part of [Train Station](https://github.com/jon-the-dev/saas-train-station), a tiered
learning platform. This repo holds the **free** lessons for this track. **6 additional
premium lessons** — CDK Workshop, CloudFormation Reference Architectures,
IaC testing with Terratest, Pulumi Examples, and more — are available in the
Train Station app.

## Lessons

| # | Lesson | Type | Level | Source |
|---|--------|------|-------|--------|
| 1 | [AWS CloudFormation Workshop](lesson-01-aws-cloudformation-workshop/) | Lab | Beginner | [AWS](https://catalog.workshops.aws/cfn101/) |
| 2 | [OpenTofu](lesson-02-opentofu/) | Repo | Intermediate | [Linux Foundation](https://github.com/opentofu/opentofu) |

Each lesson is a self-contained guide (overview, prerequisites, key takeaways, and a
step-by-step walkthrough). Open a lesson directory to read its `README.md`.
